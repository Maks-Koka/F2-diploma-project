# Висновки

Проаналізовано три діючі аналоги за шістьма технічними критеріями. Встановлено, що жоден аналог не
публікує відтворюваної методики ранжування з довірчим інтервалом, а два з них залежать від скрейпінгу
або умов доступу соціальних платформ. Сформульовано архітектурний trade-off проєкту DemandLens:
звуження набору джерел до офіційних API в обмін на правову стійкість і відтворюваність результату.
